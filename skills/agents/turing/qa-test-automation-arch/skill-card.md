## Description:

Helps QA engineers design maintainable test automation architectures with layered tests, framework selection, data management, and CI integration.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokxi](https://clawhub.ai/user/kokxi)

### License/Terms of Use:

MIT-0

## Use Case:

QA engineers and developers use this skill to plan or refactor automated testing frameworks before writing tests. It guides test-layer design, framework selection, test-data separation, maintenance, and CI integration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The suggested unpinned installation command may fetch an unreviewed release.

Mitigation: Review its source and pin a vetted version before running the command.

Risk: Real customer, identity, payment, or screenshot data may be exposed when supplied to the workflow.

Mitigation: Use synthetic test data or mask sensitive information before sharing inputs.
