## Known Risks and Mitigations:

Risk: Password-removal examples can be misused on protected PDFs without permission.

Mitigation: Use password-removal commands only for PDFs you own or are explicitly authorized to access.

Risk: Optional PDF, OCR, and command-line dependencies can introduce supply-chain or environment risk.

Mitigation: Install optional packages in a virtual environment from trusted sources and prefer pinned versions.

Risk: PDF manipulation commands can alter or expose document contents when applied to sensitive files.

Mitigation: Review proposed commands before execution and process sensitive PDFs only in approved local environments.
